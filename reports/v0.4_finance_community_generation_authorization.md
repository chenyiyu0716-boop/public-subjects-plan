## AutoDL 实例步骤（与陪伴域相同模式）

在 **数据盘** `/root/autodl-tmp` 操作：

```bash
cd /root/autodl-tmp
git clone -b v0.4-vertical-lift https://github.com/chenyiyu0716-boop/public-subjects-plan.git
cd public-subjects-plan
git pull   # 确保含 FC 云端脚本 commit

export VLIFT_WORKDIR=/root/autodl-tmp/vlift-run
export VLIFT_REPO_ROOT=/root/autodl-tmp/public-subjects-plan
export VLIFT_API_KEY=vlift-local

bash scripts/vlift_autodl_bootstrap_fc_v0.4.sh
bash scripts/vlift_autodl_run_fc_public.sh
```

生成完成后（脚本内已 `pkill` vLLM）：

1. **在 AutoDL 控制台关机/销毁实例**（关闭计费）  
2. 拉回 tarball：`$VLIFT_WORKDIR/vlift_fc_public_responses_v0.4.tgz`  
3. 本地 integrity + 报告：

```bash
python3 scripts/vlift_fc_generation_report.py \
  --workdir /path/to/vlift-run/logs/parent \
  --out reports/v0.4_fc_generation_summary.json
```

4. **暂停** — 向用户报告：有效回复数、失败项、实际费用、模型 revision/hash、provenance  
5. **再申请** LLM 盲评授权
